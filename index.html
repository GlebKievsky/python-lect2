С чего начинаем

Что уже умеем и куда идём

В прошлой теме программа выполняла все строки подряд. Что бы ни ввёл человек, она делала одно и то же. Сегодня это изменится: программа начнёт выбирать, какие строки выполнять.

Что уже умеем

  • выводить и спрашивать: print(), input();
  • превращать типы: int(), float(), str();
  • считать, включая // и %;
  • склеивать и повторять строки, мерить их через len();
  • выводить значения в f-строках.

Что будем уметь через час

  • сравнивать значения;
  • выполнять разные команды в разных случаях;
  • объединять несколько условий;
  • проверять, что ввод правильный;
  • доставать из строки буквы и куски;
  • приводить ввод к одному виду.

На КР

В программе с контрольной почти всегда есть меню: человек вводит номер пункта, а программа выбирает действие. Это и есть условия. Вторая половина темы — строки — нужна, чтобы программа не ломалась от лишнего пробела или большой буквы в ответе.

1

Правда и ложь

Тип bool и сравнения

Чтобы выбирать, программа должна уметь задавать вопросы с ответом «да» или «нет». Для таких ответов есть отдельный тип — bool, логический. У него всего два значения: True (правда) и False (ложь). Оба пишутся с большой буквы.

Вопрос задают операторы сравнения. Результат любого сравнения — значение типа bool.

ВыражениеРезультатПояснение
5 > 3TrueБольше.
5 < 3FalseМеньше.
5 >= 5TrueБольше или равно.
5 <= 4FalseМеньше или равно.
5 == 5TrueРавно. Два знака!
5 != 5FalseНе равно.
7 % 2 == 1TrueСначала арифметика, потом сравнение: 7 — нечётное?
Ловушка

Один знак = — это присваивание: «пусть имя указывает на значение». Два знака == — это вопрос: «равны ли значения?». Перепутать их — самая частая ошибка в этой теме.

Результат сравнения можно сохранить в переменную, как любое другое значение.

Двойное сравнение 0 <= points <= 100 читается как в математике: «points не меньше 0 и не больше 100». Так удобно проверять, что число попало в нужный промежуток.

Строки тоже можно сравнивать

На равенство строки сравниваются символ за символом. Важно всё: большие буквы, пробелы, каждая точка.

ВыражениеРезультатПояснение
"да" == "да"TrueОдинаковые.
"да" == "Да"FalseРазные: большая и маленькая буква — это разные символы.
"да" == "да "FalseРазные: во второй строке в конце пробел.
"abc" < "abd"TrueБольше и меньше для строк — это порядок как в словаре.
"10" > "9"FalseЛожь! Строки сравниваются по первому символу: «1» стоит раньше «9».
10 > 9TrueА числа сравниваются как числа.

Отсюда правило: числа сравниваем как числа. Если значение пришло из input(), сначала превращаем его через int() или float().

Итог раздела

  • Сравнение даёт True или False. Это тип bool.
  • == спрашивает «равно ли?», = присваивает.
  • Строки равны, только если совпадает каждый символ.
2

if и else

Выбор из двух вариантов

Команда if переводится как «если». После неё пишут условие — выражение, которое даёт True или False. Если условие истинно, выполняются строки под if. Если ложно — строки под else («иначе»).

Разберём, как это устроено.

  • Двоеточие. Строка с if и строка с else заканчиваются двоеточием. Оно говорит: «дальше идёт блок».
  • Блок. Блок — это несколько строк, которые выполняются вместе. В Python блок задаётся отступом: каждая его строка начинается с четырёх пробелов. В Spyder отступ ставит клавиша Tab.
  • Конец блока. Блок заканчивается там, где заканчиваются отступы. Строка print("Следующий!") стоит без отступа, поэтому выполняется в любом случае.

Ветка else не обязательна. Если её нет и условие ложно, программа просто идёт дальше.

Две ошибки, которые будут у каждого

Забыли отступ — Python не понимает, где блок.

Забыли двоеточие — Python подсказывает, чего он ждал.

Итог раздела

  • if условие: — блок выполняется, только если условие истинно.
  • else: — блок на случай, когда условие ложно.
  • Блок — это строки с отступом в четыре пробела. В конце заголовка — двоеточие.
3

elif

Выбор из нескольких вариантов

Вариантов часто больше двух. Для этого есть elif — сокращение от «else if», «иначе если». Получается лестница условий.

Python идёт по лестнице сверху вниз. Он проверяет условия по очереди и выполняет первую ветку, условие которой истинно. Остальные ветки он уже не проверяет. Ветка else срабатывает, если не подошло ни одно условие.

Поэтому во второй строке лестницы не нужно писать «от 6 до 12». Раз мы дошли до elif hour < 12, значит, первое условие было ложным и час уже не меньше 6.

Тренажёр 1

Лестница elif

Двигай ползунок. Следи, какие условия Python проверяет и на какой ветке останавливается.

  1. if hour < 6:
  2. print("Доброй ночи!")
  3. elif hour < 12:
  4. print("Доброе утро!")
  5. elif hour < 18:
  6. print("Добрый день!")
  7. else:
  8. print("Добрый вечер!")
Что на экране

Порядок условий важен

Раз выполняется первая подходящая ветка, условия нужно ставить в правильном порядке. Вот лестница, в которой порядок перепутан.

У студента 95 баллов, а программа говорит просто «сдано». Условие points >= 50 истинно для 95, и до второй ветки дело не доходит. Правило: в лестнице сначала идут самые «строгие» условия.

Несколько if подряд — это не лестница

Если написать несколько отдельных if, Python проверит каждое условие. Сработать могут сразу несколько.

Как выбрать

Нужен ровно один ответ из нескольких — пиши if / elif / else. Каждую проверку нужно сделать отдельно, и ответов может быть несколько — пиши несколько if подряд.

Итог раздела

  • Лестница if / elif / else выполняет ровно одну ветку — первую подходящую.
  • Порядок условий в лестнице важен.
  • Отдельные if проверяются все, независимо друг от друга.

and, or, not

Несколько условий сразу

В клуб пускают, если гостю есть 18 лет и у него есть билет. Это два условия, и нужны оба. Условия соединяют логические операторы.

aba and ba or bnot a
TrueTrueTrueTrueFalse
TrueFalseFalseTrueFalse
FalseTrueFalseTrueTrue
FalseFalseFalseFalseTrue
  • and («и») — правда, только если верны оба условия.
  • or («или») — правда, если верно хотя бы одно.
  • not («не») — переворачивает ответ.

Во второй строке справа стоит сравнение. В переменную has_ticket попадает его результат: True или False. Такую переменную можно ставить в условие без всякого ==.

Условия с остатком от деления

«Делится на 3» в Python записывают как «остаток от деления на 3 равен нулю». Такие проверки удобно соединять.

Порядок действий

Сначала выполняются сравнения, потом not, потом and, и в самом конце or. Скобки меняют порядок. Если сомневаешься — ставь скобки, с ними условие ещё и легче читать.

ВыражениеРезультатПояснение
True or False and FalseTrueСначала and: False and False даёт False. Потом True or False.
(True or False) and FalseFalseСкобки первыми: True and False.
not 5 > 3FalseСначала сравнение: 5 > 3 даёт True, потом not.

Двойное сравнение — это короткая запись для and. «Число вне промежутка» записывают через or.

ВыражениеРезультатПояснение
0 <= x <= 100FalseТо же, что 0 <= x and x <= 100.
x < 0 or x > 100TrueЧисло вне промежутка от 0 до 100.
Ловушка

По-русски мы говорим: «если ответ равен "да" или "yes"». Но запись answer == "да" or "yes" неверна: Python считает её всегда истинной. С каждой стороны от or должно стоять полное сравнение: answer == "да" or answer == "yes".

    Вложенные условия

    Проверка ввода и случайные числа

    Внутри блока можно написать ещё один if. Он называется вложенным. Его блок сдвигается ещё на четыре пробела.

    Главное применение — проверка ввода. Человек может ввести что угодно: ноль, отрицательное число, лишний пробел. Хорошая программа сначала отсекает плохой ввод и только потом считает.

    В прошлой теме такая программа падала с ошибкой ZeroDivisionError. Теперь деление стоит в ветке else и выполняется только с правильным числом людей.

    Флаг: запоминаем результат нескольких проверок

    Иногда проверок несколько, и о каждой проблеме нужно сообщить отдельно. А в конце — сказать, всё ли в порядке. Для этого заводят переменную типа bool. Её называют флагом. Сначала флаг «поднят». Каждая проверка, которая нашла проблему, его «опускает».

    Здесь три отдельных if, а не лестница: сумка может быть и длинной, и тяжёлой сразу. Последняя строка с условием читается почти по-русски: «если разрешено».

    Случайные числа

    Для игр нужен случай. Его даёт модуль random. Функция random.randint(a, b) возвращает случайное целое число от a до b. Обе границы входят.

    У тебя выпадет другое число, и при каждом запуске оно будет новым.

    Итог раздела

    • Вложенный if — это if внутри блока, с двойным отступом.
    • Сначала отсекаем неправильный ввод, потом считаем.
    • Флаг — переменная bool, которая помнит результат проверок.
    • random.randint(1, 6) — случайное целое от 1 до 6.

    Строка по буквам

    Индексы и срезы

    Строка — это цепочка символов. У каждого символа есть номер. Этот номер называется индексом. Главная неожиданность: счёт начинается с нуля.

    ВыражениеРезультатПояснение
    word[0]'П'Первый символ. Его индекс — 0.
    word[1]'и'Второй символ.
    word[4]'н'Последний: в слове 5 символов, индексы от 0 до 4.
    word[-1]'н'Отрицательный индекс считает с конца: -1 — последний.
    word[-2]'о'Предпоследний.
    len(word)5Длина строки.
    word[5]IndexErrorОшибка: символа с индексом 5 нет.

    Последняя строка таблицы — ошибка IndexError: string index out of range. Она значит: «такого номера в строке нет».

    Срез: кусок строки

    Срез вырезает из строки кусок. В квадратных скобках через двоеточие пишут, откуда начать и где остановиться. Символ с номером «стоп» в срез не входит.

    ВыражениеРезультатПояснение
    word[0:3]'Пит'С индекса 0 до индекса 3, не включая 3.
    word[1:4]'ито'Символы с индексами 1, 2, 3.
    word[:2]'Пи'Начало можно не писать: от самого начала.
    word[2:]'тон'Конец можно не писать: до самого конца.
    word[-3:]'тон'Последние три символа.
    word[:-1]'Пито'Всё, кроме последнего символа.
    word[::2]'Птн'Третье число — шаг: каждый второй символ.
    word[::-1]'нотиП'Шаг -1: строка задом наперёд.
    Тренажёр 3

    Индексы и срезы

    Над каждым символом — его индекс, под ним — индекс с конца. Меняй числа или выбери готовый пример. Пустое поле значит «не указано».

    Индекс и срез можно вычислить

    В квадратных скобках может стоять не только число, но и выражение. Например, половина длины строки.

    Срезы хорошо работают вместе с повторением строк из прошлой темы. Так прячут часть секретного слова.

    Строку нельзя изменить

    Символ в строке можно прочитать, но нельзя заменить. Строки в Python неизменяемы.

    Чтобы «изменить» строку, собирают новую из кусков старой. Имя потом перевешивают на новую строку.

    Итог раздела

    • Индексы начинаются с нуля. s[0] — первый символ, s[-1] — последний.
    • Срез s[старт:стоп] не включает символ с номером «стоп».
    • s[:n] — первые n символов, s[-n:] — последние n, s[::-1] — наоборот.
    • Строку нельзя изменить, можно только собрать новую.

    Методы строк

    Как понять ответ человека

    На вопрос «Продолжить? (да/нет)» люди отвечают по-разному: да, Да, ДА, да с пробелами. Для человека это одно и то же. Для сравнения == — четыре разные строки. Чтобы программа понимала любой вариант, ответ сначала приводят к одному виду.

    Это делают методы. Метод — это функция, которая «принадлежит» значению. Его вызывают через точку: сначала значение, потом точка, потом имя метода со скобками.

    ВыражениеРезультатПояснение
    text.strip()'Привет, Мир!'Убирает пробелы в начале и в конце.
    text.lower()' привет, мир! 'Все буквы маленькие.
    text.upper()' ПРИВЕТ, МИР! 'Все буквы большие.
    text.replace("Мир", "Питон")' Привет, Питон! 'Заменяет один кусок на другой.
    text.replace(" ", "")'Привет,Мир!'Замена на пустую строку удаляет все пробелы.
    text.count("и")2Сколько раз кусок встречается в строке.
    text.strip().startswith("При")TrueНачинается ли строка с этого куска?
    text.strip().endswith("!")TrueЗаканчивается ли строка этим куском?
    "2026".isdigit()TrueСостоит ли строка только из цифр?
    "20a6".isdigit()FalseНет: внутри буква.
    "Питон".isalpha()TrueСостоит ли строка только из букв?
    Ловушка

    Строку нельзя изменить, поэтому метод не меняет её, а возвращает новую строку. Этот результат нужно сохранить, иначе он пропадёт.

    Цепочка методов: приводим ввод к одному виду

    Методы можно вызывать один за другим. Цепочка читается слева направо: input() вернул строку, strip() убрал пробелы по краям, lower() сделал буквы маленькими. Сравнивать после этого нужно с маленькими буквами.

    Что сделает метод

    Представь, что программа выполнила text = input(). Напечатай ответ человека или выбери готовый.

    ВыражениеРезультат

    Оператор in: есть ли кусок внутри строки

    Оператор in («в») проверяет, встречается ли одна строка внутри другой. Результат — True или False.

    ВыражениеРезультатПояснение
    "@" in "max@mail.com"TrueВ адресе есть знак @.
    "кот" in "котлета"TrueКусок «кот» встречается в слове.
    " " in "без_пробелов"FalseПробела внутри нет.
    "я" not in "команда"Truenot in — «не встречается».

    Число ли это?

    Теперь можно закрыть дыру из прошлой темы. Раньше программа падала, если вместо числа вводили слово. Метод isdigit() позволяет проверить строку до того, как превращать её в число.

    Итог раздела

    • Метод вызывают через точку: text.lower(). Он возвращает новую строку.
    • Ответ человека приводим к одному виду: input(...).strip().lower().
    • in проверяет, есть ли кусок внутри строки.
    • isdigit() проверяет, что в строке только цифры.

    Практикум: фейсконтроль

    1. Сравнение даёт True или False. == сравнивает, = присваивает.

    Проверь себя

    Восемь вопросов

    Сначала ответь сам — вслух или на бумаге. Потом открой ответ и честно отметь результат.

    Чем = отличается от ==?

    = — присваивание: имя начинает указывать на значение. == — сравнение: вопрос «равны ли значения?», ответ True или False. В условии после if почти всегда нужен ==.

    Почему "10" > "9" даёт False, а 10 > 9 — True?

    Строки сравниваются по символам, как слова в словаре. Первый символ "1" стоит раньше, чем "9", поэтому строка "10" «меньше». Числа сравниваются как числа. Вывод: ввод сначала превращаем через int().

    В лестнице первым стоит условие points >= 50, вторым — points >= 90. Что получит студент с 95 баллами?

    Ответ из первой ветки. Условие 95 >= 50 истинно, Python выполняет эту ветку и остальные не проверяет. Чтобы работало верно, условие points >= 90 нужно поставить первым.

    Подбери x, y и z, при которых (x or y) and (z or not y) истинно.

    Подходят четыре набора из восьми. Если y ложно, достаточно x = True: вторая скобка истинна из-за not y. Если y истинно, первая скобка уже истинна, и нужно z = True. Проверить любой набор можно в тренажёре 2.

    Собери из строки s = "Hello World" слово "Wolle" с помощью индексов и срезов.

    Один из способов: s[6:8] + s[2:4] + s[1]. Срез s[6:8] даёт "Wo", срез s[2:4] — "ll", а s[1] — букву "e". Проверить можно в тренажёре 3.

    Что делает strip() и зачем он нужен после input()?

    strip() убирает пробелы в начале и в конце строки. Человек легко ставит лишний пробел, а для == строки "да" и "да " разные. После strip() случайный пробел программе не мешает.

    Почему условие answer == "да" or "yes" истинно всегда? Как записать правильно?

    Справа от or стоит не сравнение, а просто строка "yes". Непустую строку Python считает правдой, поэтому всё условие истинно при любом ответе. Правильно: answer == "да" or answer == "yes".

    Выполнили word = "кот", затем word[0] = "р". Что произойдёт? Как получить "рот"?

    Будет ошибка TypeError: строку нельзя изменить. Нужно собрать новую строку: word = "р" + word[1:].
